# Versteckter Demo-Cheat

Dreimal innerhalb von 1,2 Sekunden auf die Geldanzeige oben tippen oder klicken: +100.000 DM. Jeder abgeschlossene Dreifach-Tipp kann erneut verwendet werden. Einzelne oder doppelte Klicks lösen nichts aus. Tastaturaktivierung des fokussierten Feldes funktioniert ebenfalls.

Die Gutschrift wird sofort gespeichert, funktioniert bei 0 DM und erhält Nachkommastellen. Sie verändert nur das verfügbare Geld, keine Umsätze, Gewinne, Gäste oder Restaurantinvestitionen. Es gibt keinen zusätzlichen sichtbaren Menüpunkt.

Implementierung: `pizza.js`, `#moneyCheat` in `pizza.html`. Browserprüfung: `tests/pizza-demo-cheat-browser-qa.cjs`.
